# Mail servers that belong to temporary / disposable email services.
#
# Why: temp-mail sites hand out brand-new domains every few days, so any list
# of domains falls behind. Their new domains still point their MX records at
# the same few mail servers, so an address whose domain's mail goes to one of
# these servers is refused even when the domain itself is on no list
# (APP/disposable.py, infrastructure_match).
#
# How it was built (2026-10-11), with scripts/disposable_mx_survey.py:
#   - resolved MX (A as the fallback) and the mail servers' addresses for
#     37,513 known disposable domains: all of disposable-email-domains and
#     7c/fakefilter (whose "## provider" headings name the service behind each
#     domain) plus a random 25,000 of mailchecker, burner-email-providers and
#     ivolo/disposable-email-domains; 8,106 of them answered with a mail server;
#   - and for domains the services were handing out that day: mail.tm
#     /domains API, temp-mail.io domains API, yopmail's domain list,
#     guerrillamail, tempmail.plus, mohmal, moakt, fakemailgenerator,
#     generator.email / emailfake.com, 10minutemail.net, mailinator, maildrop,
#     dropmail, tempr.email, temp-mail.us, tempmail.so, tempm.com.
#     temp-mail.org, 10minutemail.com, emailondeck and tempail block scripted
#     visits (Cloudflare); their servers are identified through fakefilter's
#     provider headings instead. tempmail.com is a parked page today.
#   - kept a server only when it serves many disposable domains (the count is
#     on each line) or is a temp-mail service's own named server, and its
#     address is a dedicated machine (not a shared web or mail host).
#
# Deliberately NOT here, although many disposable domains use them: Google,
# Microsoft 365, Zoho, Yandex, Proton, Fastmail, iCloud, Namecheap
# (privateemail, eforward, web-hosting, jellyfish), GoDaddy, Titan, Hostinger,
# IONOS, OVH, Gandi, Rackspace, Strato, Timeweb, Spaceship, Regery, ImprovMX,
# ForwardEmail, Cloudflare Email Routing, Mailgun, Amazon SES, SendGrid,
# AWS Global Accelerator and parking hosts. Real organisations use them; the
# domain list catches the disposable domains there. APP/disposable.py also
# refuses to treat any of them as disposable infrastructure, whatever this
# file says.
#
# Format: one entry per line, "# ..." comments. A name matches an MX host
# equal to it or under it (wabblywabble.com matches mail.wabblywabble.com).
# An address or network matches the address an MX host resolves to.
# Rebuild: run the survey, review its top hosts/addresses, edit by hand.
